# القواعد المحاسبية في قيد

1. كل عملية مالية = قيد مزدوج داخل `db.transaction()`.
2. مجموع المدين = مجموع الدائن (مع تقريب منزلتين) وإلا يُرمى استثناء.
3. الرصيد يُحسب من `journalLines`، ولا يُخزَّن رقمًا نهائيًا.
4. القيد المرحَّل لا يُحذف: إما قيد عكسي `reversalOfId` أو `status: 'VOID'`.
5. كل مستند (فاتورة/دفعة/شيك/تسوية/إقرار ضريبي) يرتبط بقيد عبر `sourceType` + `sourceId`.
6. مثال البيع 1,000 + 15%: Dr 1300 = 1,150 / Cr 4100 = 1,000 / Cr 2200 = 150.
7. عند التحصيل: Dr 1200 = 1,150 / Cr 1300 = 1,150.
