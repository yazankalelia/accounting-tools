# مجموعة أدوات محاسبية متقدمة

أداة محاسبية عربية تعمل بالكامل داخل المتصفح، في ملف HTML واحد بدون أي مكتبات خارجية أو خادم.

## الأدوات (13)

- الحاسبة المحاسبية (ذاكرة M، مجموع GT، ضريبة/خصم، سجل)
- الخصومات وأسعار الصرف
- الربح والهامش
- ضريبة القيمة المضافة (VAT)
- القروض
- الفائدة (FV/PV)
- الإهلاك
- نقطة التعادل
- NPV / IRR
- النسب المالية
- أعمار الذمم / الخسائر الائتمانية المتوقعة (ECL)
- إعادة تقييم العملات الأجنبية
- تقييم المخزون

## المزايا

- واجهة عربية كاملة مع فواصل الآلاف.
- حساب تلقائي أثناء الإدخال.
- قيود محاسبية جاهزة (مدين/دائن) مع نسخ.
- تصدير الجداول بصيغة CSV.
- تصميم متجاوب (جوال/سطح مكتب) وسمة داكنة.
- لا تُرسل أي بيانات إلى أي خادم؛ كل شيء يعمل محلياً.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

الملف ثابت (static) ويمكن نشره على GitHub Pages أو Netlify أو Vercel أو Cloudflare Pages.
