## 1. ما هو التطبيق؟

ملف HTML واحد (`index.html`) يعمل داخل المتصفح دون خادم أو مكتبات خارجية. كل البيانات تُحفظ داخل جهازك (IndexedDB + localStorage). لا تُرسل بياناتك إلى أي جهة.

- الموقع المنشور: <https://yazankalelia.github.io/accounting-tools/>
- المصدر: `C:\Users\Yazan\calculator.html` → نسخة النشر `C:\Users\Yazan\accounting-tools\index.html`
- المستودع: `yazankalelia/accounting-tools`، الفرع `main`
- اللغة: عربية كاملة + إنجليزية (زر EN/AR أسفل القائمة الجانبية)
- المظهر: داكن/فاتح/تلقائي

## 2. التشغيل

1. افتح الرابط أعلاه، أو افتح `index.html` مباشرةً.
2. للتشغيل المحلي: `python -m http.server 8000` ثم `http://localhost:8000`.
3. لا يوجد تسجيل دخول ولا اسم مستخدم/كلمة مرور — البيانات مرتبطة بالمتصفح والجهاز.

## 3. البيانات والخصوصية

| العنصر | المكان |
|---|---|
| القيود/الفواتير/الشركاء/الشيكات/دليل الحسابات | IndexedDB باسم `supercalc` (الإصدار 3) |
| الإعدادات والنسخة الاحتياطية المؤقتة | `localStorage` (مفاتيح `sc:*`) |
| النسخة الاحتياطية الكاملة | زر «نسخ احتياطي/تصدير كامل» → ملف JSON |

**مهم:** data محلية على جهاز واحد فقط. انسخ ملف JSON الاحتياطي أسبوعيًا إلى مكان آمن (قرص خارجي/سحابة شخصية). مسح بيانات المتصفح = فقدان البيانات إن لم يكن لديك ملف JSON.

## 4. خريطة الأدوات (18 صفحة)

### الأدوات اليومية
- **حاسبة**: ذاكرة M/MC/MR/M+/M−، المجموع الكلي GT، ضريبة/خصم، Round 2، سجل العمليات، نسخ النتيجة، اختصارات لوحة المفاتيح.
- **خصومات/عملات**: خصم متعدد، تحويل عملات مع أسعار حية محفوظة عند انقطاع الاتصال.
- **أسعار العملات**: أسعار حية لـ10 عملات، تثبيت أهم 3 عملات، وقت آخر تحديث.
- **ربح/هامش**: تكلفة/بيع/هامش/ربح مع القيد المحاسبي.
- **VAT**: صافي المستحق/الاسترداد، متعدد المعدلات، **ملخص ربع سنوي** من القيود المرحّلة (2200 مخرجات / 2210 مدخلات) + قيد الإقفال.

### الأصول والتمويل
- **قروض**: PMT وجدول إطفاء (أول 24 دفعة).
- **فائدة FV/PV**: القيمة المستقبلية/الحالية وجدول الفوائد.
- **إهلاك**: جداول الإهلاك والقيمة الدفترية، و IFRS 9 لمخصص الخسائر الائتمانية.

### التحليل والاستثمار
- **تعادل**: نقطة التعادل (Break-even).
- **NPV/IRR**: صافي القيمة الحالية ومعدل العائد الداخلي.
- **نسب مالية**: 10 نسب رئيسية + معايير مقارنة (Benchmark).

### المحاسبة التجارية (جديدة)
- **الفواتير والدفاتر**: الشركاء + الفواتير + الأرصدة + كشف الحساب + CSV.
- **الشيكات**: واردة/صادرة + استحقاق + تحصيل/صرف + ارتداد + قيود تلقائية.

### العمليات والتقييم
- **أعمار ديون**: AR/AP Aging مع شرائح عمرية.
- **إعادة تقييم FX**: فروق العملات الأجنبية.
- **مخزون**: تقييم المخزون.
- **تسوية بنكية**: استيراد كشف CSV ومطابقة تلقائية + قيد تسوية.

### السجل والتدقيق
- **السجل والقيود**: القيود المرحّلة، البحث/الفلاتر، ميزان المراجعة، قائمة الدخل، الميزانية العمومية، قائمة التدفقات النقدية، سجل التدقيق، نسخ JSON، تصدير CSV.

## 5. سير العمل المحاسبي الكامل (خطوة بخطوة)

### 5.1 إعداد الشركة مرة واحدة
1. «إعدادات التقارير» (في صفحة السجل والقيود) → اكتب **اسم المؤسسة** والفترة.
2. ارفع **الشعار** (PNG/JPG/WebP حتى 3MB) — يظهر في رأس الطباعة/PDF.
3. «دليل الحسابات» → راجع الـ24 حسابًا جاهزًا وعدّل الأسماء/الرموز حسب نظامك.

### 5.2 القيود اليومية
1. «السجل والقيود» → أنشئ قيدًا بالتاريخ والبيان والسطور (مدين/دائن).
2. «ترحيل» ينشئ رقمًا تسلسليًا `JE-YYYYMM-0001`، ويحفظ القيد في دفتر الأستاذ.
3. الترقيم ذري محليًا (kv `jeSeq`) ولا يتكرر؛ القيد المعكوس يبقى الأصل ويُنشأ قيد معاكس مرتبط به.
4. لا يمكن حذف قيد مرحّل — يُعكس فقط (سجل تدقيق سليم).

### 5.3 الشركاء (دائنون/مدينون)
1. «الفواتير والدفاتر» → بطاقة «الشركاء»: الاسم، النوع (زبون/مورد/كلاهما)، الهاتف، الرقم الضريبي، رصيد افتتاحي واتجاهه (عليه مدين/له دائن).
2. **استيراد دفتر الشركاء**: نزّل «قالب CSV»، املأه، ثم «استيراد من CSV». الأعمدة: الاسم، النوع، الهاتف، الرقم الضريبي، رصيد افتتاحي، الاتجاه.
3. زر «كشف» يعرض الرصيد الافتتاحي + كل الفواتير المرحّلة والرصيد المتحرك، وقابل للطباعة.

### 5.4 الفواتير
1. «فاتورة جديدة»: اختر النوع (مبيعات/مشتريات)، الشريك، التاريخ، البيان.
2. اختر **الحساب المالي** (الإيرادات للمبيعات، المصروف للمشتريات) ونسبة الضريبة (16/10/5/0%).
3. أضف البنود (بيان/كمية/سعر) — المجموع والضريبة والإجمالي تُحسب لحظيًا.
4. «حفظ مسودة» أو «حفظ + ترحيل قيد»:
   - مبيعات: Dr المدينون 1300 (الإجمالي) / Cr الإيرادات (المجموع الفرعي) / Cr ضريبة المخرجات 2200 (الضريبة).
   - مشتريات: Dr المصروف (المجموع الفرعي) + Dr ضريبة المدخلات 2210 / Cr الدائنون 2100 (الإجمالي).
5. الترقيم التلقائي: `F-YYYY-0001`. الطباعة تخرج فاتورة بترويسة الشركة والشعار والتوقيع والختم.

### 5.5 الشيكات
1. «شيك جديد»: وارد (لنا) أو صادر (علينا)، الجهة (من دفتر الشركاء أو اسم حر)، المصرف، رقم الشيك، الاستحقاق، المبلغ.
2. «تحصيل» (وارد): Dr البنك 1200 / Cr المدينون 1300. «صرف» (صادر): Dr الدائنون 2100 / Cr البنك 1200.
3. «مرتجع» و«إلغاء» لتغيير الحالة؛ «إلغاء التسوية» ينشئ قيدًا معاكسًا. لا يمكن حذف شيك مُحصّل.
4. الفلاتر: النوع، الحالة، الاستحقاق خلال 7/30 يومًا أو المتأخرة.

### 5.6 التقارير النهائية
- **ميزان المراجعة**: من القيود المرحّلة حتى تاريخ «إلى»، مع الأرصدة الافتتاحية.
- **قائمة الدخل**: حركة الفترة «من–إلى».
- **الميزانية العمومية**: الأرصدة حتى «إلى».
- **قائمة التدفقات النقدية** (غير مباشرة).
- **ملخص VAT ربع السنوي**: من قيود الفواتير.
- **أعمار الذمم + النسب المالية + ECL (IFRS 9)**.
- كلها قابلة للطباعة/PDF وCSV.

### 5.7 النسخ الاحتياطي
- «السجل والقيود» → تصدير كامل JSON (كل الجداول بما فيها الفواتير والشيكات) → احفظه خارج الجهاز.
- الاستعادة من نفس الواجهة. لا توجد مزامنة تلقائية (لا سحابة).

### 5.8 الجوال واللمس
- شريط سفلي ثابت: حاسبة · VAT · أسعار العملات · السجل · «المزيد» (يفتح درج كل الأدوات).
- أزرار كبيرة ≥52px وتأثير ضغط مرئي (يُعطّل تلقائيًا إن كان «تقليل الحركة» مفعّلًا).
- «الأكثر استخدامًا»: أعلى القائمة، يتعلم من استخدامك ويُحفظ محليًا.

### 5.9 اختصارات لوحة المفاتيح
`Enter` نتيجة · `Esc` تصفير · `⌫` حذف · `F2` السجل · `/` بحث · `Alt+T` ضريبة · `Ctrl+P` طباعة/PDF · `?` كل الاختصارات.

## 6. القيود المعروفة

- مستخدم واحد/جهاز واحد — لا مشاركة بين زملاء (الوضع السحابي أُلغي طلبًا).
- الاستيراد يدعم CSV فقط؛ `.xlsx` يحتاج مكتبة SheetJS (لم تُضف).
- لا ربط بـFawtara/E-invoicing الأردني، ولا إقرار ضريبي رسمي — ملخص VAT تقريبي للمراجعة.
- إقفال السنة وتسويات نهاية السنة يدوية.
- ترقيم الفواتير يستمر حتى لو حُذفت مسودة (فجوة مقبولة محليًا).
- لا نسخ احتياطي تلقائي مجدول — ملف JSON يدوي.
