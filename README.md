# قيد — منظومة المحاسبة الاحترافية (QAYD)

**QAYD — Professional Accounting System**

أداة محاسبية عربية تعمل بالكامل داخل المتصفح، في ملف HTML واحد بدون أي مكتبات خارجية أو خادم.

## الأدوات (14)

- الحاسبة المحاسبية (ذاكرة M، مجموع GT، ضريبة/خصم، سجل)
- الخصومات وأسعار الصرف
- الربح والهامش
- ضريبة القيمة المضافة (VAT) — متعدد المعدلات
- القروض
- الفائدة (FV/PV)
- الإهلاك
- نقطة التعادل
- NPV / IRR
- النسب المالية (مع معيار Benchmark)
- أعمار الذمم / الخسائر الائتمانية المتوقعة (ECL)
- إعادة تقييم العملات外国ية
- تقييم المخزون
- أسعار العملات العالمية (تحويل مباشر بين 10 عملات بأسعار حية، مع تثبيت أهم 3 عملات)

## المزايا

- واجهة عربية كاملة مع دعم الإنجليزية (تبديل لغة) وفواصل الآلاف.
- حساب تلقائي أثناء الإدخال.
- قيود محاسبية جاهزة (مدين/دائن) مع نسخ.
- رسوم بيانية للتقارير (إيرادات/مصروفات/صافي).
- تصدير الجداول بصيغة CSV.
- تصميم متجاوب (جوال/سطح مكتب) وسمة داكنة، مع شريط علوي وقائمة أدوات سفلية مجمّعة على الجوال.
- لوحة مفاتيح الحاسبة باتجاه LTR القياسي.
- أسعار عملات حية من مصدر مجاني بدون مفتاح، مع حفظ آخر نسخة للعمل دون إنترنت وعرض وقت آخر تحديث.
- صندوق ملاحظات عائم يُرسل ملاحظات الزوار إلى Google Sheets مع اسم المرسل قبل النص.
- لا تُرسل بياناتك المحاسبية إلى أي خادم؛ فقط نص الملاحظة يُرسل عند ضغطك على «إرسال».

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

الملف ثابت (static) ويمكن نشره على GitHub Pages أو Netlify أو Vercel أو Cloudflare Pages.
